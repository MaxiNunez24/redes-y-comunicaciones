# HTTP

El campo de Host: dominio sirve para que en un mismo servidor (con una única IP) se puedan alojar varios sitios web. El servidor web puede diferenciar a qué sitio web se está accediendo a partir del valor del campo Host: dominio.


## Códigos de respuestas HTTP
- HTTP/<version> 200 OK
- HTTP/<version> 301 Moved Permanently
- HTTP/<version> 400 Bad Request
- HTTP/<version> 403 Access Forbidden
- HTTP/<version> 404 Not Found
- HTTP/<version> 405 Method Not Allowed
- HTTP/<version> 500 Internal Server Error (CGI Error)
- HTTP/<version> 501 Method Not Implemented

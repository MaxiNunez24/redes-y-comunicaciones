## Ejemplos prácticos 

El campo de Host: dominio sirve para que en un mismo servidor (con una única IP) se puedan alojar varios sitios web. El servidor web puede diferenciar a qué sitio web se está accediendo a partir del valor del campo Host: dominio.


## Códigos de respuestas HTTP
- **HTTP/<version> 200 OK**: La solicitud se ha procesado correctamente.
- **HTTP/<version> 301 Moved Permanently**: El recurso solicitado ha sido movido permanentemente a una nueva ubicación.
- **HTTP/<version> 400 Bad Request**: La solicitud no se pudo entender debido a un error de sintaxis.
- **HTTP/<version> 403 Access Forbidden**: El servidor entiende la solicitud, pero se niega a fulfillla.
- **HTTP/<version> 404 Not Found**: El recurso solicitado no se encontró en el servidor.
- **HTTP/<version> 405 Method Not Allowed**: El método de solicitud utilizado no está permitido para el recurso solicitado.
- **HTTP/<version> 500 Internal Server Error**: Error interno del servidor al procesar la solicitud.
- **HTTP/<version> 501 Method Not Implemented**: El método de solicitud utilizado no está implementado por el servidor.

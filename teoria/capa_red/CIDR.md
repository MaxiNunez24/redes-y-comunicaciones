# CIDR (Classless Inter-Domain Routing)

## Introducción
CIDR es un método de asignación de direcciones IP y enrutamiento que reemplaza el sistema de clases de direcciones IP (A, B, C, D y E) utilizado anteriormente. Fue introducido para mejorar la eficiencia en el uso de direcciones IP y para permitir una mayor flexibilidad en la asignación de direcciones. CIDR permite que las direcciones IP se representen de manera más compacta y eficiente, utilizando una notación de prefijo que indica cuántos bits de la dirección IP se utilizan para la parte de red y cuántos para la parte de host.

### Ejemplos
- Una dirección IP con CIDR se representa como `192.168.1.1/24`
- En este ejemplo, `192.168.1.1` es la dirección IP y `24` es la longitud del prefijo, lo que indica que los primeros 24 bits son la parte de red y los últimos 8 bits son la parte de host.

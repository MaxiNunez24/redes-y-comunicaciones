# Práctica 2 - Capa de Aplicación (HTTP)

## Introducción

### 1. ¿Cuál es la función de la capa de aplicación?
Las funciones de la capa de aplicación son:
- Proveer servicios de comunicación a los usuarios (Conocidos como Capa 8) y a las aplicaciones, incluye las aplicaciones mismas.

- Proveer servicios de comunicación en el modelo Machine to machine (M2M), sin usuarios (personas)

- Brindar una Interfaz con el usuario, User Interface (UI), o una Interfaz con las aplicaciones, Application Programming Interface (API).

- Tanto las aplicaciones que usan la red como los protocolos que implementan las aplicaciones pertenecen a esta capa.
